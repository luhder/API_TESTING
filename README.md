# API Testing with Postman 🚀
**Overview**
This project includes API testing using Postman, covering various HTTP methods like GET, POST, PUT, DELETE. It validates API responses, checks performance, and automates test execution.

**Tools & Technologies**

*Postman – Manual API testing

*Newman (CLI Runner) – Automated API testing

*JavaScript – Postman test scripts

*JSON – API request and response payloads

**API Test Scenarios**

✔️ Verify API response status codes

✔️ Check response time and headers

✔️ Validate JSON response structure & values
